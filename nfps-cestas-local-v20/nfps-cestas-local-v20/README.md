# NFPS Cestas

Site local em HTML e CSS para divulgação das cestas básicas da NFPS Cestas em Patrocínio-MG.

## Como usar

Abra o arquivo `index.html` no navegador.

## Como publicar

Envie o conteúdo desta pasta para o GitHub e conecte o repositório à Vercel.
